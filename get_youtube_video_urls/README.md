## Description

Get video urls from a YouTube channel or playlist. `yt-dlp` script for audio and video is available.

- Download [yt-dlp](https://github.com/yt-dlp/yt-dlp/releases)
- Copy yt-dlp.exe to this folder
- Download and install [FFMPEG](https://www.gyan.dev/ffmpeg/builds/). FFMPEG merges video and audio after download, else they will be separated.
